# DaletDEX

> One account. Many routes.

DaletDEX is a cryptocurrency wallet and exchange. From one account you can buy, sell, accept, and store assets such as Bitcoin, Ethereum, and USDT — with both a simple quick-trade flow and a professional exchange interface.

The product is built around clarity and trust: secure wallets, fast settlement, and support that stays available when you need it.
